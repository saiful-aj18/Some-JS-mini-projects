# 🚀 Some JS Mini Projects

A collection of beginner-friendly JavaScript mini projects built using **HTML, CSS, and Vanilla JavaScript**.
This repository is focused on improving core JavaScript concepts through practical projects and interactive UI components.

Whether you're learning DOM manipulation, event handling, API integration, or local storage — these projects help strengthen real-world frontend development skills.

## 📌 Features

* Multiple JavaScript mini projects in one repository
* Beginner-friendly code structure
* Responsive UI designs
* Pure HTML, CSS & JavaScript
* Hands-on practice with DOM manipulation
* Interactive and reusable components

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## 📂 Projects Included

* Calculator
* Model pop up
* To-Do App
* Simple tabs
* Counter App

## 🎯 Learning Goals

This repository helps practice:

* DOM Manipulation
* Event Handling
* Functions & Logic Building
* Local Storage

* JavaScript Fundamentals
